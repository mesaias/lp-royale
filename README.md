# LP Royale

Real-time, multi-device Life Points tracker for Yu-Gi-Oh! Battle Royale duels (2-4 players).
Contador de Life Points en tiempo real y multidispositivo para duelos Battle Royale de Yu-Gi-Oh! (2-4 jugadores).

## Download / Descarga

- **Android (APK):** [Latest release / Última versión](../../releases/latest). Download `app-arm64-v8a-release.apk`, which works on almost all modern phones.
- **Web:** https://lifepoints-royale-tracker.web.app (no install needed / sin instalar)

### Install the APK / Instalar el APK

1. Download the APK from the latest release. / Descarga el APK de la última versión.
2. Open it. If Android asks, allow installs from this source (your browser or file manager). / Ábrelo. Si Android lo pide, permite instalar desde esta fuente.
3. If Play Protect shows a warning, tap **More details** then **Install anyway**. The app is not on Google Play. / Si Play Protect muestra una advertencia, toca **Más detalles** y luego **Instalar de todos modos**. La app no está en Google Play.

To update, install the newer APK over the old one. / Para actualizar, instala el APK nuevo encima del anterior.

### Install the web app as an app / Instalar la web como app

On Android Chrome, open the web URL and choose **Install app** or **Add to Home screen**. It updates automatically.
En Chrome para Android, abre la URL y elige **Instalar app** o **Añadir a la pantalla de inicio**. Se actualiza sola.

## Features / Funciones

- Create or join a room with a code; every device sees LP changes live. / Crea o únete a una sala con un código; todos los dispositivos ven los cambios al instante.
- 2-4 players, plus Tag Duel (team) modes. / 2-4 jugadores, más modos Tag Duel (por equipos).
- Dice roll and coin toss to decide turn order. / Dados y moneda para decidir el orden de turnos.
- Custom damage/heal numpad, undo last change. / Teclado de daño/curación personalizado, deshacer último cambio.
- LP chart, duel history and win/loss stats. / Gráfica de LP, historial de duelos y estadísticas.
- Spectator (guest) mode. / Modo espectador (invitado).
- Battle music and sound effects. / Música de batalla y efectos de sonido.
- English and Spanish. / Inglés y español.
